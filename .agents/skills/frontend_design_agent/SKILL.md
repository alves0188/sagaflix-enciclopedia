# Front-End Designer Skill

Este agente é especializado na codificação e estilização de interfaces modernas e responsivas para o Sagaflix, utilizando CSS Vanilla e design premium.

## Diretrizes de Atuação

1. **Acessibilidade Estética (Aesthetics)**:
   - Utilizar paletas de cores harmoniosas com tons escuros (dark mode) combinados com detalhes dourados (`var(--accent-gold)`) e bordas suaves (`var(--border-color)`).
   - Implementar efeitos modernos como gradientes suaves e transparências em desfoque (glassmorphic glass).

2. **Tipografia Premium**:
   - Garantir hierarquia clara de títulos (Playfair Display, Outfit ou Inter) e textos para facilitar a leitura prolongada de livros e dossiês.

3. **CSS Otimizado**:
   - Manter estilos limpos no `index.css` e CSS local dos componentes.
   - Utilizar variáveis CSS globais para facilitar modificações visuais em lote.
